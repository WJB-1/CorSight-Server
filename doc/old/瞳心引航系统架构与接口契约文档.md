# **瞳心引航：系统架构与接口契约文档 (API Contract)**

## **1\. 架构概述 (Architecture Overview)**

“瞳心引航”采用标准的 **端-边-云-物 (Device-Edge-Cloud-IoT)** 五层解耦架构。系统旨在兼顾“基于大模型的强认知能力”与“毫秒级物理避障的绝对安全”。

整体架构被切分为以下五个独立模块，各模块通过严格的协议进行通信，支持前后端、算法、硬件团队并行开发：

1. **街景数据库网络层 (Data Layer)**：云端基础设施，存储离散物理语义。  
2. **安卓 UI 端网络层 (Client Layer)**：交互中枢，负责传感器统筹与信息呈现。  
3. **Agent 端网络层 (Orchestration Layer)**：云端智慧大脑，负责业务调度与推理。  
4. **安卓小模型端 (Edge AI Layer)**：本地边缘计算，负责 0 延迟保命避障。  
5. **嵌入式硬件端 (IoT Sensor Layer)**：物联网感知延伸，提供第一人称视觉。

## **2\. 模块分层与接口协议定义**

### **模块 1：街景数据库网络层 (Data Layer \- Backend)**

* **核心职责**：作为系统的“底层基建”，存储和查询物理世界的离散语义节点。仅对内（Agent层）服务。  
* **部署栈**：Node.js / Python (搭配 MongoDB 的 2dsphere 空间索引)  
* **通信协议**：内部 HTTP (RESTful API)

**接口 1.1：空间范围特征查询 (Radius Query)**

* **调用方**：Agent 端  
* **请求地址**：GET /api/db/points/nearby  
* **参数 (Query)**：lat=23.1364 & lon=113.3223 & radius=50  
* **响应示例 (JSON)**：  
  {  
    "status": "success",  
    "data": \[  
      {"type": "crosswalk", "has\_traffic\_light": true, "distance": 15},  
      {"type": "obstacle", "desc": "盲道被违停车辆阻断", "distance": 40}  
    \]  
  }

**接口 1.2：沿途特征批量查询 (Route Query \- 用于行前预览)**

* **调用方**：Agent 端  
* **请求地址**：POST /api/db/points/route  
* **请求体**：高德 API 返回的途径坐标点串 \[{"lat":..., "lon":...}, ...\]  
* **响应**：沿途交汇的所有高危节点与语义信息。

### **模块 2：安卓 UI 端网络层 (Client Layer \- App)**

* **核心职责**：系统的交互枢纽。向上请求云端 Agent 进行复杂推理，向下调度底层模型与硬件。  
* **部署栈**：Android 原生 (Java/Kotlin)  
* **通信协议**：HTTP (基于 SSE 的流式传输) / WebSocket

**接口 2.1：唤醒行前预览工作流 (HTTP POST \+ SSE)**

* **流转目标**：发往 Agent 端 (/api/agent/preview\_workflow)  
* **请求体 (JSON)**：  
  {  
    "user\_id": "vip\_001",  
    "user\_voice": "我要去图书馆，尽量避开天桥",  
    "current\_gps": {"lat": 23.0364, "lon": 113.3223}  
  }

* **响应机制**：采用 Server-Sent Events (SSE)，接收流式文本，Android 端接收后即刻调用百度 TTS 分片播报，将等待延迟压缩至 1 秒内。

**接口 2.2：实时环境问答通道 (WebSocket)**

* **流转目标**：发往 Agent 端 (ws://server/agent/chat)  
* **通信机制**：全双工通信，前端推送语音文本与当前摄像头帧，接收云端 VLM 返回的精简指令。

### **模块 3：Agent 端网络层 (Orchestration Layer \- Cloud Brain)**

* **核心职责**：系统的“大脑调度器”。接收前端请求，拉取数据库信息，组装 Prompt 喂给千问大模型，提取结果下发前端。  
* **部署栈**：Python (FastAPI \+ LangChain/原生工作流)  
* **通信协议**：对外提供 HTTP/WS 接口，对内调用阿里云/千问 API。

**接口 3.1：多模态大模型推理调度 (内部中继逻辑)**

* **调用方**：Agent 端业务逻辑  
* **流转目标**：千问 API / 阿里云百炼平台  
* **组装 Payload (JSON)**：  
  {  
    "model": "qwen-max",  
    "input": {  
      "messages": \[  
        {"role": "system", "content": "你是视障导航助手，必须使用钟表方位词，恪守静默原则..."},  
        {"role": "user", "content": "用户位置X，周边节点Y（来自模块1），请生成50字内的前方路况沙盘预览..."}  
      \]  
    }  
  }

### **模块 4：安卓小模型端部署 (Edge AI Layer \- Local Inference)**

* **核心职责**：处理最高优先级的“保命”任务（如悬空障碍物检测、盲道偏航）。**必须 0 延迟、断网可用**。  
* **部署栈**：TFLite / NCNN 部署于 Android 底层  
* **通信协议**：Android 本地内存调用 (JNI / C++ Binder)

**接口 4.1：模型初始化与卸载**

* **方法定义**：initVisionModel(String modelPath, float threshold)  
* **说明**：App 启动或进入导航模式时，将轻量级视觉模型加载进 RAM/NPU。

**接口 4.2：帧处理与威胁评估引擎 (高频调用)**

* **方法定义**：ThreatReport analyzeFrame(Bitmap frame)  
* **响应机制**：每秒处理 15-30 帧，当检测到威胁阈值超过安全设定时，返回拦截回调。  
  {  
    "has\_danger": true,  
    "danger\_type": "悬空树枝",  
    "distance\_estimate": "0.8m",  
    "action": "TRIGGER\_HAPTIC\_BEEP" // UI 层直接执行震动和蜂鸣，不经过网络  
  }

### **模块 5：嵌入式采集项链 (IoT Sensor Layer \- Hardware)**

* **核心职责**：代替手机摄像头，提供第一人称视角的稳定图像流，彻底解放视障用户的双手。  
* **部署栈**：ESP32-CAM / 树莓派 Zero  
* **通信协议**：BLE (低功耗蓝牙控制) / UDP (局域网图传)

**接口 5.1：设备配对与状态控制 (BLE)**

* **通信机制**：Android UI 端与 ESP32 通过蓝牙特征值 (Characteristics) 交互。  
* **核心指令**：写入 Wi-Fi 热点凭证、读取设备电量、控制外接补光灯。

**接口 5.2：实时视频流中继 (UDP/MJPEG)**

* **通信机制**：ESP32 建立轻量级 Stream Server，Android 端直连其局域网 IP 拉取数据。  
* **流地址**：http://192.168.43.x:81/stream  
* **约束**：输出固定尺寸（如 640x480）和帧率（15fps）的连续 JPEG 帧，直接喂给**模块 4**进行边缘推理。

## **3\. 典型系统流转链路 (Data Flow Example)**

**场景：行进中物理避障（静默原则示范）**

1. **\[模块5\] IoT 硬件** 捕捉到前方 1 米处有一辆共享单车阻断盲道，通过局域网 UDP 将图像帧发送给手机。  
2. **\[模块4\] 边缘模型** 接收帧数据，毫秒级本地运算得出结论：distance: 1m, threat: high。  
3. **\[模块2\] 安卓 UI 端** 监听到回调，**不经过任何网络请求**，立刻调用马达执行急促震动，发出滴滴警报音（恪守静默原则，不主动长篇大论）。  
4. **用户交互**：用户察觉异样，停下脚步，双击屏幕主动发问：“前面挡路的是什么？”。  
5. **\[模块2 \-\> 模块3\]**：安卓端截取当前帧和录音，通过 WebSocket 发往 **Agent 端**。  
6. **\[模块3 \-\> 千问VL\]**：Agent 端封装图片和 Prompt 调用云端视觉大模型。  
7. **\[模块3 \-\> 模块2\]**：云端返回自然语言反馈：“正前方一米有一辆黄色共享单车横放，建议用盲杖向左侧两点钟方向探路绕行。”
