## 1. 项目概述

### 1.1 OSM for the Blind 项目介绍

**OSM for the Blind** 是 OpenStreetMap 社区中一个专注于为视障人士提供无障碍地图数据的项目。该项目致力于通过完善地图数据中的无障碍属性，帮助视障用户更好地理解和导航周围的世界。

**核心目标：**
- 为视障用户提供高质量的触觉地图数据
- 推动无障碍相关地图标签的标准化和完善
- 促进视障导航应用和辅助工具的开发
- 建立全球视障地图数据贡献者社区

### 1.2 为视障人士提供无障碍地图数据

视障人士需要地图数据包含以下特殊信息：
- 触觉路面（tactile paving）的位置和类型
- 声音信号（sound signals）的分布
- 无障碍设施（accessibility features）的详细标注
- 盲文信息（Braille information）的位置
- 安全过街点的精确位置
- 危险区域和障碍物的标注

### 1.3 相关项目和工具

| 项目名称 | 类型 | 说明 |
|---------|------|------|
| Look and Listen Map | 交互式有声地图 | 基于 OSM 数据的视障友好地图 |
| Project BlindOSM | 数据采集项目 | 专注于视障相关数据的 OSM 项目 |
| OSM2Tactile | 触觉地图生成 | 将 OSM 数据转换为触觉地图 |
| YouDescribe | 众包描述 | 为地图元素添加语音描述 |

## 2. 视障导航核心标签体系

### 2.1 触觉路面标签（Tactile Paving）

触觉路面是视障导航中最重要的基础设施之一。OSM 使用以下标签进行标注：

#### 基础标签

| 标签 | 值 | 说明 | 使用场景 |
|-----|-----|------|---------|
| `tactile_paving` | `yes` | 有触觉路面 | 任何有触觉路面的路径 |
| `tactile_paving` | `no` | 无触觉路面 | 确认无触觉路面的路径 |
| `tactile_paving` | `contrasted` | 对比色触觉路面 | 低视力用户可见的对比色路面 |
| `tactile_paving` | `primitive` | 简易触觉路面 | 非标准但可用的触觉路面 |
| `tactile_paving` | `incorrect` | 错误的触觉路面 | 不符合标准或误导性的路面 |

#### 详细类型标签

| 标签 | 值 | 说明 |
|-----|-----|------|
| `tactile_paving:orientation` | `parallel` | 条形方向与行进方向平行（导向条） |
| `tactile_paving:orientation` | `perpendicular` | 条形方向与行进方向垂直（警示条） |
| `tactile_paving:pattern` | `dots` | 点状图案（警示点） |
| `tactile_paving:pattern` | `lines` | 线条图案（导向条） |
| `tactile_paving:pattern` | `bars` | 条形图案 |
| `tactile_paving:pattern` | `lozenges` | 菱形图案 |

#### 使用示例

```
# 有标准触觉路面的行人过街
highway=crossing
+tactile_paving=yes
+tactile_paving:orientation=perpendicular
+tactile_paving:pattern=dots

# 有导向条的盲道
highway=footway
+footway=sidewalk
+tactile_paving=yes
+tactile_paving:orientation=parallel
+tactile_paving:pattern=lines
```

### 2.2 声音信号标签（Sound Signals）

声音信号帮助视障人士判断何时可以安全过街。

| 标签 | 值 | 说明 |
|-----|-----|------|
| `traffic_signals:sound` | `yes` | 交通信号灯有声音提示 |
| `traffic_signals:sound` | `no` | 无声音提示 |
| `traffic_signals:sound` | `walk` | 仅在可通行时发出声音 |
| `traffic_signals:sound` | `beep` | 蜂鸣声提示 |
| `traffic_signals:sound` | `chirp` | 鸟鸣声提示 |
| `traffic_signals:sound` | `tactile` | 触觉（振动）提示 |
| `traffic_signals:sound` | `locator` | 定位声音（持续发出以帮助找到按钮） |
| `traffic_signals:button` | `yes` | 有按钮可激活声音 |
| `traffic_signals:button` | `no` | 无按钮 |
| `traffic_signals:button` | `tactile` | 有触觉按钮 |
| `traffic_signals:button` | `wheelchair` | 有轮椅/触觉按钮 |

#### 使用示例

```
# 带有声音提示和触觉按钮的行人过街信号灯
highway=traffic_signals
+traffic_signals:sound=walk
+traffic_signals:button=tactile
+traffic_signals:orientation=0  # 面向0度方向
```

## 3. 如何为视障人士绘制地图

### 3.1 绘制地图的注意事项

#### 精确性要求
- **位置精度**：触觉路面、过街点等元素的定位误差应控制在1米以内
- **方向精度**：信号灯朝向、触觉路面方向等信息必须准确
- **完整性**：确保所有相关属性都被标注，不遗漏关键信息
- **一致性**：同一区域内的标注方式应保持一致

#### 数据验证
- 实地验证：建议通过实地走访确认数据准确性
- 照片记录：拍摄现场照片作为数据参考
- 交叉验证：与其他数据源进行交叉比对
- 社区审核：提交社区审核以确保数据质量

### 3.2 重要性和优先级

#### 高优先级数据
1. **行人过街点**：包括信号灯、触觉路面、声音提示
2. **公共交通站点**：公交站台、地铁站的无障碍设施
3. **主要人行道**：盲道、触觉路面的分布
4. **重要建筑物入口**：医院、学校、政府机构的入口无障碍信息
5. **楼梯和坡道**：位置、台阶数、扶手信息

#### 中优先级数据
1. **次要道路**：人行道、小巷的无障碍信息
2. **公共设施**：公园、广场的无障碍设施
3. **商业设施**：商店、餐厅的无障碍入口

#### 低优先级数据
1. **住宅区内部**：住宅区内的人行道信息
2. **非必要设施**：装饰性元素、非功能性设施

### 3.3 视障用户需要的数据类型

#### 导航数据
- 可通行路径网络
- 障碍物位置和类型
- 安全过街点
- 公共交通连接
- 目的地入口位置

#### 环境感知数据
- 周围建筑物类型
- 道路宽度和类型
- 人行道状况
- 交通流量信息
- 声音环境描述

#### 辅助设施数据
- 触觉路面分布
- 声音信号位置
- 盲文信息位置
- 无障碍设施分布
- 求助点/紧急呼叫点

## 4. 自动化触觉地图生成服务

### 4.1 触觉地图生成工具

#### OSM2Tactile
- **功能**：将 OSM 数据转换为触觉地图格式
- **输入**：OSM XML/JSON 数据
- **输出**：触觉地图文件（支持多种格式）
- **特点**：自动识别触觉路面、障碍物等关键元素
- **使用场景**：批量生成特定区域的触觉地图

#### 触觉地图生成流程
```
OSM 数据提取 -> 数据预处理 -> 触觉元素识别 -> 地图布局 -> 输出文件
```

### 4.2 相关 Web 服务

| 服务名称 | 网址 | 功能 |
|---------|------|------|
| OSM2Tactile Web | 在线服务 | 在线生成触觉地图 |
| Tactile Map Generator | 在线服务 | 自定义触觉地图生成 |
| OSM Accessibility Map | 在线服务 | 无障碍地图可视化 |
| BlindMap | 在线服务 | 视障友好地图浏览 |

### 4.3 地图打印和制作

#### 打印规格
- **纸张类型**：厚卡纸（250gsm以上）或专用触觉纸
- **打印方式**：激光打印或专用触觉打印机
- **分辨率**：至少300 DPI
- **缩放比例**：根据区域大小调整，通常1:1000到1:5000

#### 制作流程
1. 数据提取：从 OSM 提取目标区域数据
2. 数据筛选：保留触觉相关元素
3. 布局设计：设计触觉地图布局
4. 打印输出：使用专用设备打印
5. 质量检查：验证触觉元素可辨识性

## 5. 视障地图项目（Look and Listen Map）

### 5.1 交互式有声地图

**Look and Listen Map** 是一个基于 OSM 数据的交互式有声地图项目，专为视障用户设计。

**核心功能：**
- 语音播报地图元素
- 触觉反馈交互
- 实时导航指引
- 环境声音模拟
- 自定义路线规划

### 5.2 项目介绍和链接

- **项目主页**：提供项目介绍和使用指南
- **在线演示**：可在浏览器中体验有声地图
- **API 接口**：提供数据接口供第三方应用使用
- **开源代码**：代码托管在开源平台

### 5.3 相关竞赛和活动

- **OpenStreetMap Accessibility Mapping Party**：定期举办的地图绘制活动
- **Look and Listen Map Challenge**：鼓励开发者为视障用户创建地图应用
- **Tactile Map Design Competition**：触觉地图设计竞赛

## 7. 其他可做的事情

### 7.1 添加触觉 paving 标签

#### 标注流程
1. 识别触觉路面类型（导向条/警示点）
2. 确定路面方向（平行/垂直）
3. 记录路面状况（完好/损坏/部分）
4. 添加 OSM 标签

#### 常见场景
- **盲道**：沿人行道延伸的导向条
- **过街点**：斑马线两端的警示点
- **楼梯口**：楼梯顶部和底部的警示路面
- **站台边缘**：火车站/地铁站台边缘的警示路面
- **入口区域**：建筑物入口的导向路面

### 7.2 添加声音信号标签

#### 标注要点
- 确认声音类型（蜂鸣/鸟鸣/语音）
- 记录按钮位置和类型
- 标注信号灯朝向
- 记录声音触发方式

#### 常见场景
- **行人信号灯**：有声音提示的行人过街灯
- **地铁站**：列车到达的音频提示
- **公交站**：公交车到达的音频提示
- **电梯**：楼层播报和开关门提示
- **自动门**：感应和开启提示音

### 7.3 添加无障碍设施标签

#### 标注范围
- **建筑物入口**：无障碍入口、自动门、坡道
- **公共交通**：无障碍站台、低地板车辆
- **公共设施**：无障碍厕所、无障碍电梯
- **商业设施**：无障碍通道、无障碍停车位
- **信息设施**：盲文标识、音频信息

### 7.4 添加盲文信息标签

#### 标注要点
- 确认盲文内容类型（菜单/地图/信息）
- 记录盲文位置（入口/电梯/服务台）
- 标注盲文语言
- 记录盲文更新日期

#### 常见场景
- **餐厅**：盲文菜单
- **酒店**：盲文房间号和设施说明
- **医院**：盲文科室分布和导诊信息
- **博物馆**：盲文展品说明
- **公共交通**：盲文线路图和时刻表

## 19. 附录：标签速查表

### A. 触觉路面标签速查

```
# 基础标签
tactile_paving=yes/no/contrasted/primitive/incorrect

# 方向
tactile_paving:orientation=parallel/perpendicular

# 图案
tactile_paving:pattern=dots/lines/bars/lozenges

# 使用场景
highway=footway + footway=sidewalk + tactile_paving=yes
highway=crossing + tactile_paving=yes + tactile_paving:orientation=perpendicular
highway=steps + tactile_paving:warning=yes
```

### B. 声音信号标签速查

```
# 基础标签
traffic_signals:sound=yes/no/walk/beep/chirp/tactile/locator

# 按钮
traffic_signals:button=yes/no/tactile/wheelchair

# 完整示例
highway=traffic_signals
+traffic_signals:sound=walk
+traffic_signals:button=tactile
+traffic_signals:orientation=0
```

### C. 无障碍设施标签速查

```
# 通用
wheelchair=yes/no/limited/designated
access=yes/no/private

# 盲文
braille=yes/no
braille:menu=yes
braille:room_numbers=yes
braille:elevator=yes
braille:atm=yes
braille:information=yes
braille:map=yes

# 公共交通
audio_information=yes/no/timetable/next_departures/stop_name
departure_board=yes/tactile/braille
blind_guide=yes/no/tactile/audio/personal
```

### D. 过街标签速查

```
# 基础
highway=crossing
crossing=uncontrolled/traffic_signals/unmarked/zebra

# 辅助
crossing:island=yes/no
crossing:markings=yes/no/dashes/dots/zebra
crossing:light=yes/no

# 完整示例
highway=crossing
+crossing=traffic_signals
+tactile_paving=yes
+traffic_signals:sound=walk
+traffic_signals:button=tactile
+crossing:island=yes
+kerb=lowered
```

### E. 路缘石标签速查

```
# 基础
kerb=raised/lowered/flush/rolled/no

# 高度
kerb:height=0.15  # 15厘米

# 旧标签（建议使用 kerb）
sloped_curb=yes/no/at_crossing/both
```

### F. 楼梯标签速查

```
# 基础
highway=steps
step_count=10

# 扶手
handrail=yes/no/left/right/center

# 坡道
ramp=yes/no
ramp:wheelchair=yes
ramp:stroller=yes

# 触觉警示
tactile_paving:warning=yes
```

### G. 电梯标签速查

```
# 基础
highway=elevator

# 操作
button_operated=yes/no
voice_operated=yes/no
automatic_door=yes/no

# 无障碍
door:width=1.2
capacity:persons=8
maxweight=1.5

# 辅助功能
braille=yes
tactile_buttons=yes
audio_announcement=yes/no/floor/direction/door
```

### H. 公共交通标签速查

```
# 基础
highway=bus_stop / railway=station

# 无障碍
wheelchair=yes/no/limited/designated
shelter=yes/no
bench=yes/no

# 信息
audio_information=yes/no/timetable/next_departures/stop_name
departure_board=yes/tactile/braille
passenger_information_display=yes/no

# 导盲

tactile_paving:platform=yes
```
