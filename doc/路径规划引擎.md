## 1. 概述

GraphHopper Directions API 是一个高性能的路线规划服务，基于 OpenStreetMap (OSM) 数据构建。它为开发者提供了一套完整的地理空间 API，支持多种交通方式、自定义路线偏好和复杂的路线优化。

### 1.1 核心特性

| 特性 | 说明 |
|------|------|
| **多交通方式** | 汽车、自行车、步行、轮椅、摩托车等 |
| **全球覆盖** | 基于 OSM 数据，覆盖全球道路网络 |
| **实时计算** | 服务器端实时路径计算 |
| **自定义偏好** | 支持自定义路线权重和避让规则 |
| **批量计算** | 矩阵 API 支持多点间批量距离/时间计算 |
| **可达性分析** | 等时线 API 计算可达范围 |
| **轨迹校正** | 地图匹配 API 将 GPS 轨迹匹配到道路 |

### 1.2 基础 URL

```
https://graphhopper.com/api/1
```

### 1.3 视障导航相关功能

对于视障导航应用，以下 API 功能尤为重要：

- **步行模式 (`foot`)**: 专为行人优化的路线
- **轮椅模式 (`wheelchair`)**: 无障碍路线，避开楼梯、陡坡等障碍
- **避让选项**: 可避开隧道、收费站、未铺装道路等
- **详细导航指令**: 提供转弯提示、距离、街道名称
- **可达性分析**: 计算特定时间/距离内可达的区域

## 2. 认证与授权

### 2.1 获取 API Key

1. 访问 [GraphHopper 官网](https://www.graphhopper.com/) 注册账号
2. 在 Dashboard 中创建应用并获取 API Key
3. 免费计划每天提供 500 credits

### 2.2 认证方式

所有 API 请求都需要通过 `key` 参数传递 API Key：

```
GET https://graphhopper.com/api/1/route?key=YOUR_API_KEY&...
```

### 2.3 安全建议

- **客户端应用**: 不要将 API Key 硬编码在客户端代码中，应通过后端代理转发请求
- **服务器端应用**: 将 API Key 存储在环境变量中
- **密钥轮换**: 定期更换 API Key，在 Dashboard 中可重新生成

```python
# Python: 从环境变量读取 API Key
import os

API_KEY = os.environ.get('GRAPHHOPPER_API_KEY')
if not API_KEY:
    raise ValueError('GRAPHHOPPER_API_KEY 环境变量未设置')
```

```javascript
// JavaScript/Node.js: 从环境变量读取 API Key
const API_KEY = process.env.GRAPHHOPPER_API_KEY;
if (!API_KEY) {
    throw new Error('GRAPHHOPPER_API_KEY 环境变量未设置');
}
```

### 4.2 Python 客户端示例

```python
import requests
import json

class GraphHopperClient:
    """GraphHopper API 客户端"""
    
    BASE_URL = "https://graphhopper.com/api/1"
    
    def __init__(self, api_key):
        self.api_key = api_key
    
    def _request(self, endpoint, params):
        """发送通用 HTTP 请求"""
        params['key'] = self.api_key
        url = f"{self.BASE_URL}/{endpoint}"
        
        response = requests.get(url, params=params, timeout=30)
        response.raise_for_status()
        return response.json()
    
    def route(self, **kwargs):
        """路线规划"""
        return self._request('route', kwargs)
    
    def matrix(self, **kwargs):
        """距离/时间矩阵"""
        return self._request('matrix', kwargs)
    
    def geocode(self, **kwargs):
        """地理编码"""
        return self._request('geocode', kwargs)
    
    def isochrone(self, **kwargs):
        """等时线"""
        return self._request('isochrone', kwargs)
    
    def match(self, **kwargs):
        """地图匹配"""
        return self._request('match', kwargs)
```

### 4.3 JavaScript/Node.js 客户端示例

```javascript
class GraphHopperClient {
    constructor(apiKey) {
        this.apiKey = apiKey;
        this.baseUrl = 'https://graphhopper.com/api/1';
    }
    
    async _request(endpoint, params) {
        const queryParams = new URLSearchParams({
            ...params,
            key: this.apiKey
        });
        
        const url = `${this.baseUrl}/${endpoint}?${queryParams}`;
        const response = await fetch(url);
        
        if (!response.ok) {
            throw new Error(`HTTP ${response.status}: ${response.statusText}`);
        }
        
        return response.json();
    }
    
    async route(params) {
        return this._request('route', params);
    }
    
    async matrix(params) {
        return this._request('matrix', params);
    }
    
    async geocode(params) {
        return this._request('geocode', params);
    }
    
    async isochrone(params) {
        return this._request('isochrone', params);
    }
    
    async match(params) {
        return this._request('match', params);
    }
}

// 使用示例
```

### 6.3 程序化监控

```python
import requests
import time

class UsageMonitor:
    """API 使用量监控器"""
    
    def __init__(self, api_key):
        self.api_key = api_key
        self.daily_limit = None
        self.remaining = None
        self.reset_time = None
    
    def check_usage(self):
        """检查当前使用量"""
        # 发送一个轻量级请求获取响应头
        url = f"https://graphhopper.com/api/1/route?key={self.api_key}"
        response = requests.get(url, timeout=10)
        
        self.daily_limit = response.headers.get('X-RateLimit-Limit')
        self.remaining = response.headers.get('X-RateLimit-Remaining')
        self.reset_time = response.headers.get('X-RateLimit-Reset')
        
        return {
            'limit': self.daily_limit,
            'remaining': self.remaining,
            'reset_time': self.reset_time,
            'used_percentage': (
                (int(self.daily_limit) - int(self.remaining)) / int(self.daily_limit) * 100
                if self.daily_limit and self.remaining else None
            )
        }
    
    def should_warn(self, threshold=80):
        """检查是否超过警告阈值"""
        usage = self.check_usage()
        return usage['used_percentage'] and usage['used_percentage'] > threshold
```

## 7. 常见工作流

### 7.1 视障导航典型工作流

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   用户输入地址   │────▶│  地理编码 API   │────▶│  获取坐标 (lat,lon)│
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                        │
┌─────────────────┐     ┌─────────────────┐     ┌───────▼─────────┐
│  语音播报导航指令 │◄────│  解析路由响应   │◄────│   路由 API      │
│  (turn-by-turn)  │     │  (instructions) │     │ (foot/wheelchair)│
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                        │
                                               ┌────────▼────────┐
                                               │  OSM 地图数据   │
                                               │  (道路、人行道)  │
                                               └─────────────────┘
```

### 7.2 最佳实践

1. **先地理编码，再路由**: 将用户输入的地址转换为坐标后再请求路线
2. **缓存结果**: 缓存常用地址的坐标和路线结果
3. **批量处理**: 使用矩阵 API 批量计算多点间距离
4. **错误降级**: 主 API 失败时提供备用方案
5. **预加载**: 在用户输入时预加载可能的路线

## 8. 优化响应速度

### 8.1 请求优化

| 优化方法 | 说明 | 效果 |
|----------|------|------|
| **减少路径点** | 只发送必要的路径点 | 减少计算量 |
| **限制备选方案** | `alternative_route.max_paths=1` | 减少计算量 |
| **简化几何** | `points_encoded=true` | 减少传输量 |
| **使用 POST** | 大量路径点时用 POST | 避免 URL 过长 |
| **指定区域** | 使用 `bbox` 限制搜索范围 | 减少计算量 |

### 8.2 缓存策略

```python
import hashlib
import json
import time
from functools import lru_cache

class CachedGraphHopperClient:
    """带缓存的 GraphHopper 客户端"""
    
    def __init__(self, api_key, cache_ttl=3600):
        self.api_key = api_key
        self.cache = {}
        self.cache_ttl = cache_ttl  # 缓存有效期（秒）
    
    def _get_cache_key(self, endpoint, params):
        """生成缓存键"""
        # 排除 API key 和动态参数
        cache_params = {k: v for k, v in params.items() if k != 'key'}
        param_str = json.dumps(cache_params, sort_keys=True)
        return f"{endpoint}:{hashlib.md5(param_str.encode()).hexdigest()}"
    
    def _get_from_cache(self, cache_key):
        """从缓存获取"""
        if cache_key in self.cache:
            data, timestamp = self.cache[cache_key]
            if time.time() - timestamp < self.cache_ttl:
                return data
            else:
                del self.cache[cache_key]
        return None
    
    def route(self, **params):
        """带缓存的路线规划"""
        cache_key = self._get_cache_key('route', params)
        cached = self._get_from_cache(cache_key)
        
        if cached:
            return cached
        
        # 调用实际 API（此处简化）
        result = self._call_api('route', params)
        self.cache[cache_key] = (result, time.time())
        return result
```

## 9. 地图数据与路线档案

### 9.1 地图数据来源

GraphHopper 使用 **OpenStreetMap (OSM)** 数据：

- **更新频率**: 每周更新
- **覆盖范围**: 全球
- **数据类型**: 道路、人行道、建筑物、兴趣点等
- **标签系统**: OSM 使用键值对标签描述地图要素

### 9.2 内置路线档案

| 档案名称 | 适用场景 | 说明 |
|----------|----------|------|
| `car` | 汽车驾驶 | 最快路线，考虑交通限制 |
| `bike` | 自行车 | 避开高速公路，优先自行车道 |
| `mtb` | 山地自行车 | 优先越野路线 |
| `racingbike` | 公路自行车 | 优先铺装路面 |
| `foot` | 步行 | 优先人行道，允许步行街 |
| `hike` | 徒步 | 优先自然路径 |
| `wheelchair` | 轮椅 | 无障碍路线，避开楼梯 |
| `motorcycle` | 摩托车 | 考虑摩托车限制 |
| `truck` | 卡车 | 考虑限高、限重 |

### 9.3 视障导航推荐档案

对于视障导航应用，推荐使用以下档案：

#### 9.3.1 步行模式 (`foot`)

```
profile=foot
```

- 优先人行道
- 允许步行街
- 考虑人行横道
- 适合大多数步行导航场景

#### 9.3.2 轮椅模式 (`wheelchair`)

```
profile=wheelchair
```

- **自动避开**: 楼梯、陡坡、未铺装路面
- **优先选择**: 平坦路面、无障碍设施
- **适合场景**: 轮椅用户、行动不便者、视障用户（需要平坦路面时）

## 10. 核心 API 详解

### 10.1 路由 (Routing)

路线规划是 GraphHopper 的核心功能，计算两点或多点之间的最优路径。

#### 10.1.1 API 端点

```
GET https://graphhopper.com/api/1/route
```

#### 10.1.2 请求参数

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `point` | string | 是 | 路径点，格式 `lat,lon` | `52.516,13.377` |
| `profile` | string | 是 | 路线档案 | `foot`, `wheelchair`, `car` |
| `key` | string | 是 | API Key | `your-api-key` |
| `locale` | string | 否 | 导航指令语言 | `zh_CN`, `en` |
| `instructions` | boolean | 否 | 是否返回导航指令 | `true` (默认) |
| `calc_points` | boolean | 否 | 是否返回路径几何 | `true` (默认) |
| `points_encoded` | boolean | 否 | 是否编码路径点 | `true` (默认) |
| `elevation` | boolean | 否 | 是否返回海拔数据 | `false` |
| `details` | string | 否 | 返回额外详情 | `road_class,surface` |
| `optimize` | string | 否 | 优化目标 | `false` |
| `avoid` | string | 否 | 避让选项 | `toll,ferry,motorway` |
| `ch.disable` | boolean | 否 | 禁用 contraction hierarchies | `false` |
| `custom_model` | JSON | 否 | 自定义模型 | 见自定义模型章节 |

#### 10.1.3 视障导航专用参数

```
# 步行导航（推荐）
GET /route?point=52.516,13.377&point=52.520,13.385&profile=foot&locale=zh_CN&instructions=true&details=road_class&details=surface&details=max_speed&key=YOUR_KEY

# 轮椅导航（无障碍路线）
GET /route?point=52.516,13.377&point=52.520,13.385&profile=wheelchair&locale=zh_CN&instructions=true&details=road_class&details=surface&details=max_speed&key=YOUR_KEY
```

```python
import requests
import json

class RoutingService:
    """视障导航路由服务"""
    
    def __init__(self, api_key):
        self.api_key = api_key
        self.base_url = "https://graphhopper.com/api/1/route"
    
    def get_walking_route(self, from_lat, from_lon, to_lat, to_lon, 
                          use_wheelchair=False, locale='zh_CN'):
        """
        获取步行路线
        
        Args:
            from_lat, from_lon: 起点坐标
            to_lat, to_lon: 终点坐标
            use_wheelchair: 是否使用轮椅模式（无障碍路线）
            locale: 导航指令语言
        
        Returns:
            dict: 包含路线信息、导航指令、距离、时间等
        """
        profile = 'wheelchair' if use_wheelchair else 'foot'
        
        params = {
            'point': [f'{from_lat},{from_lon}', f'{to_lat},{to_lon}'],
            'profile': profile,
            'locale': locale,
            'instructions': 'true',
            'calc_points': 'true',
            'points_encoded': 'false',
            'elevation': 'true',
            'details': ['road_class', 'surface', 'max_speed', 'toll'],
            'key': self.api_key
        }
        
        response = requests.get(self.base_url, params=params, timeout=30)
        response.raise_for_status()
        data = response.json()
        
        if 'paths' not in data or len(data['paths']) == 0:
            raise ValueError('未找到路线')
        
        path = data['paths'][0]
        
        # 解析导航指令为语音播报格式
        voice_instructions = self._parse_instructions(path.get('instructions', []))
        
        return {
            'distance_meters': path['distance'],
            'distance_text': self._format_distance(path['distance']),
            'time_ms': path['time'],
            'time_text': self._format_time(path['time']),
            'ascend': path.get('ascend', 0),
            'descend': path.get('descend', 0),
            'points': path['points'],
            'instructions': voice_instructions,
            'bbox': path.get('bbox'),
            'road_details': path.get('details', {})
        }
    
    def _parse_instructions(self, instructions):
        """解析导航指令为语音播报格式"""
        voice_instructions = []
        
        sign_map = {
            0: '继续直行',
            -2: '左转',
            2: '右转',
            -3: '向左急转',
            3: '向右急转',
            -1: '稍向左转',
            1: '稍向右转',
            -7: '靠左行驶',
            7: '靠右行驶',
            5: '到达目的地',
            4: '到达途经点'
        }
        
        for i, inst in enumerate(instructions):
            sign = inst.get('sign', 0)
            action = sign_map.get(sign, '直行')
            
            # 构建播报文本
            if sign == 5:  # 到达终点
                text = f"已到达终点"
            elif i == 0:  # 第一段
                text = f"出发，{action}进入{inst.get('street_name', '前方道路')}"
            else:
                distance_text = self._format_distance(inst['distance'])
                text = f"前方{distance_text}，{action}"
                if inst.get('street_name'):
                    text += f"进入{inst['street_name']}"
            
            voice_instructions.append({
                'index': i,
                'action': action,
                'text': text,
                'distance': inst['distance'],
                'time': inst['time'],
                'street_name': inst.get('street_name', ''),
                'coordinates': self._get_instruction_coordinates(inst)
            })
        
        return voice_instructions
    
    def _format_distance(self, meters):
        """格式化距离显示"""
        if meters < 1000:
            return f"{int(meters)}米"
        else:
            return f"{meters/1000:.1f}公里"
    
    def _format_time(self, ms):
        """格式化时间显示"""
        seconds = ms // 1000
        minutes = seconds // 60
        hours = minutes // 60
        
        if hours > 0:
            return f"{hours}小时{minutes % 60}分钟"
        else:
            return f"{minutes}分钟"
    
    def _get_instruction_coordinates(self, instruction):
        """获取导航指令对应的坐标"""
        # 从 interval 获取坐标索引范围
        interval = instruction.get('interval', [0, 0])
        return interval
```

```javascript
class VisualNavigationRouter {
    constructor(apiKey) {
        this.apiKey = apiKey;
        this.baseUrl = 'https://graphhopper.com/api/1/route';
    }
    
    async getWalkingRoute(from, to, options = {}) {
        const {
            useWheelchair = false,
            locale = 'zh_CN',
            avoid = []
        } = options;
        
        const profile = useWheelchair ? 'wheelchair' : 'foot';
        
        const params = new URLSearchParams({
            point: [`${from.lat},${from.lon}`, `${to.lat},${to.lon}`],
            profile,
            locale,
            instructions: 'true',
            calc_points: 'true',
            points_encoded: 'false',
            elevation: 'true',
            key: this.apiKey
        });
        
        // 添加避让选项
        if (avoid.length > 0) {
            params.append('avoid', avoid.join(','));
        }
        
        const url = `${this.baseUrl}?${params.toString()}`;
        const response = await fetch(url);
        
        if (!response.ok) {
            throw new Error(`路由请求失败: ${response.status}`);
        }
        
        const data = await response.json();
        
        if (!data.paths || data.paths.length === 0) {
            throw new Error('未找到路线');
        }
        
        return this._parseRoute(data.paths[0]);
    }
    
    _parseRoute(path) {
        const instructions = path.instructions.map((inst, index) => ({
            index,
            text: this._generateVoiceText(inst, index),
            distance: inst.distance,
            distanceText: this._formatDistance(inst.distance),
            time: inst.time,
            streetName: inst.street_name || '',
            action: this._getActionText(inst.sign)
        }));
        
        return {
            distance: path.distance,
            distanceText: this._formatDistance(path.distance),
            time: path.time,
            timeText: this._formatTime(path.time),
            ascend: path.ascend || 0,
            descend: path.descend || 0,
            points: path.points,
            instructions,
            bbox: path.bbox
        };
    }
    
    _generateVoiceText(inst, index) {
        const signMap = {
            0: '继续直行',
            [-2]: '左转',
            2: '右转',
            [-3]: '向左急转',
            3: '向右急转',
            [-1]: '稍向左转',
            1: '稍向右转',
            [-7]: '靠左行驶',
            7: '靠右行驶',
            5: '到达目的地',
            4: '到达途经点'
        };
        
        const action = signMap[inst.sign] || '直行';
        
        if (inst.sign === 5) {
            return '已到达终点';
        }
        
        if (index === 0) {
            return `出发，${action}${inst.street_name ? '进入' + inst.street_name : ''}`;
        }
        
        return `前方${this._formatDistance(inst.distance)}，${action}${inst.street_name ? '进入' + inst.street_name : ''}`;
    }
    
    _formatDistance(meters) {
        return meters < 1000 ? `${Math.round(meters)}米` : `${(meters/1000).toFixed(1)}公里`;
    }
    
    _formatTime(ms) {
        const minutes = Math.floor(ms / 60000);
        const hours = Math.floor(minutes / 60);
        return hours > 0 ? `${hours}小时${minutes % 60}分钟` : `${minutes}分钟`;
    }
    
    _getActionText(sign) {
        const map = { 0: 'straight', [-2]: 'left', 2: 'right', [-3]: 'sharp_left', 3: 'sharp_right', 5: 'arrive' };
        return map[sign] || 'straight';
    }
}
```

```python
import requests

class MatrixService:
    """距离/时间矩阵服务"""
    
    def __init__(self, api_key):
        self.api_key = api_key
        self.base_url = "https://graphhopper.com/api/1/matrix"
    
    def calculate_matrix(self, points, profile='foot', output_types=None):
        """
        计算距离/时间矩阵
        
        Args:
            points: [(lat, lon), ...] 坐标列表
            profile: 路线档案
            output_types: ['distances', 'times', 'weights']
        
        Returns:
            dict: 矩阵结果
        """
        if output_types is None:
            output_types = ['distances', 'times']
        
        params = {
            'profile': profile,
            'key': self.api_key
        }
        
        # 添加所有点
        for lat, lon in points:
            params.setdefault('point', []).append(f'{lat},{lon}')
        
        # 添加输出类型
        for out_type in output_types:
            params.setdefault('out_array', []).append(out_type)
        
        response = requests.get(self.base_url, params=params, timeout=60)
        response.raise_for_status()
        return response.json()
    
    def find_nearest(self, origin, destinations, profile='foot'):
        """
        找到离起点最近的地点
        
        适用于视障导航中查找最近的设施（如卫生间、公交站）
        """
        all_points = [origin] + destinations
        result = self.calculate_matrix(all_points, profile, ['distances'])
        
        distances = result['distances'][0][1:]  # 起点到各终点的距离
        
        nearest_idx = min(range(len(distances)), key=lambda i: distances[i])
        
        return {
            'index': nearest_idx,
            'point': destinations[nearest_idx],
            'distance': distances[nearest_idx]
        }


# 使用示例：查找最近的公交站

    (39.9050, 116.4080),
    (39.9030, 116.4060),
    (39.9060, 116.4090)
]

print(f"最近的公交站距离: {nearest['distance']:.0f}米")
```

```python
            self.recently_announced.add(next_instruction['index'])
```

```python
class LocationCorrector:
    """GPS 位置校正器 - 使用地图匹配"""
    
    def __init__(self, api_key):
        self.api_key = api_key
        self.matcher = MapMatchingService(api_key)
        self.gps_buffer = []
    
    def add_gps_point(self, lat, lon, timestamp):
        """添加 GPS 点"""
        self.gps_buffer.append((lat, lon, timestamp))
        
        # 当缓冲区足够时进行地图匹配
        if len(self.gps_buffer) >= 5:
            return self._correct_position()
        
        return lat, lon  # 返回原始位置
    
    def _correct_position(self):
        """校正位置"""
        result = self.matcher.match_trace(self.gps_buffer)
        
        # 清空缓冲区
        self.gps_buffer = []
        
        # 返回匹配后的最新位置
        if 'paths' in result and len(result['paths']) > 0:
            points = result['paths'][0]['points']['coordinates']
            if points:
                last_point = points[-1]
                return last_point[1], last_point[0]  # lat, lon
        
        return None
```

```python
import requests
import time
from functools import wraps

class GraphHopperError(Exception):
    """GraphHopper API 错误"""
    pass

class RateLimitError(GraphHopperError):
    """额度限制错误"""
    pass

class AuthenticationError(GraphHopperError):
    """认证错误"""
    pass

def retry_on_error(max_retries=3, delay=1):
    """重试装饰器"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(max_retries):
                try:
                    return func(*args, **kwargs)
                except requests.exceptions.HTTPError as e:
                    response = e.response
                    
                    if response.status_code == 429:
                        # 额度限制，等待后重试
                        if attempt < max_retries - 1:
                            wait_time = delay * (2 ** attempt)
                            print(f"请求过于频繁，{wait_time}秒后重试...")
                            time.sleep(wait_time)
                            continue
                        raise RateLimitError("API 额度已用完或请求过于频繁")
                    
                    elif response.status_code == 401:
                        raise AuthenticationError("API Key 无效或已过期")
                    
                    elif response.status_code == 400:
                        error_data = response.json()
                        raise GraphHopperError(f"请求参数错误: {error_data.get('message')}")
                    
                    elif response.status_code >= 500:
                        if attempt < max_retries - 1:
                            time.sleep(delay * (2 ** attempt))
                            continue
                        raise GraphHopperError("服务器错误，请稍后重试")
                    
                    raise
                except requests.exceptions.Timeout:
                    if attempt < max_retries - 1:
                        time.sleep(delay)
                        continue
                    raise GraphHopperError("请求超时")
                
                except requests.exceptions.ConnectionError:
                    if attempt < max_retries - 1:
                        time.sleep(delay)
                        continue
                    raise GraphHopperError("网络连接错误")
            
            return None
        return wrapper
    return decorator


# 使用示例
class RobustGraphHopperClient:
    """带错误处理的 GraphHopper 客户端"""
    
    def __init__(self, api_key):
        self.api_key = api_key
    
    @retry_on_error(max_retries=3, delay=1)
    def get_route(self, params):
        """获取路线（带重试）"""
        url = "https://graphhopper.com/api/1/route"
        params['key'] = self.api_key
        
        response = requests.get(url, params=params, timeout=30)
        response.raise_for_status()
        return response.json()
    
    @retry_on_error(max_retries=3, delay=1)
    def geocode(self, address):
        """地理编码（带重试）"""
        url = "https://graphhopper.com/api/1/geocode"
        params = {
            'q': address,
            'key': self.api_key
        }
        
        response = requests.get(url, params=params, timeout=10)
```

```python
from enum import Enum


class NavigationProfile(Enum):
    """导航档案类型"""
    WALKING = "foot"
    WHEELCHAIR = "wheelchair"
    BICYCLE = "bike"


@dataclass
class GeoPoint:

@dataclass
class NavigationInstruction:

class GraphHopperAPI:
    """GraphHopper API 客户端"""
    
    BASE_URL = "https://graphhopper.com/api/1"
    
    def __init__(self, api_key: str):
        self.api_key = api_key
        self.session = requests.Session()
    
    def _request(self, endpoint: str, params: dict, method='GET') -> dict:
        """发送 API 请求"""
        params['key'] = self.api_key
        url = f"{self.BASE_URL}/{endpoint}"
        
        try:
            if method == 'GET':
                response = self.session.get(url, params=params, timeout=30)
            else:
                response = self.session.post(url, json=params, timeout=30)
            
            response.raise_for_status()
            return response.json()
        except requests.exceptions.HTTPError as e:
            if e.response.status_code == 401:
                raise Exception("API Key 无效")
            elif e.response.status_code == 429:
                raise Exception("API 额度已用完")
            raise
    
    def geocode(self, query: str, locale: str = 'zh_CN') -> List[Dict]:
        """地理编码"""
        result = self._request('geocode', {
            'q': query,
            'locale': locale,
            'limit': 5
        })
        
        return [
            {
                'name': hit.get('name'),
                'lat': hit['point']['lat'],
                'lon': hit['point']['lng'],
                'address': f"{hit.get('street', '')}, {hit.get('city', '')}, {hit.get('country', '')}"
            }
            for hit in result.get('hits', [])
        ]
    
    def reverse_geocode(self, point: GeoPoint, locale: str = 'zh_CN') -> Optional[Dict]:
        """反向地理编码"""
        result = self._request('geocode', {
            'point': str(point),
            'locale': locale
        })
        
        if result.get('hits'):
            hit = result['hits'][0]
            return {
                'name': hit.get('name'),
                'address': f"{hit.get('street', '')}, {hit.get('city', '')}"
            }
        return None
    
    def route(self, from_point: GeoPoint, to_point: GeoPoint, 
              profile: NavigationProfile = NavigationProfile.WALKING,
              locale: str = 'zh_CN') -> Dict:
        """路线规划"""
        result = self._request('route', {
            'point': [str(from_point), str(to_point)],
            'profile': profile.value,
            'locale': locale,
            'instructions': 'true',
            'calc_points': 'true',
            'points_encoded': 'false',
            'elevation': 'true',
            'details': ['road_class', 'surface']
        })
        
        if not result.get('paths'):
            raise Exception("未找到路线")
        
        return result['paths'][0]
    
    def matrix(self, points: List[GeoPoint], 
               profile: NavigationProfile = NavigationProfile.WALKING) -> Dict:
        """距离矩阵"""
        point_params = [str(p) for p in points]
        
        return self._request('matrix', {
            'point': point_params,
            'profile': profile.value,
            'out_array': ['distances', 'times']
        })
    
    def isochrone(self, point: GeoPoint, time_limit: int = 600,

        return self._request('isochrone', {
            'point': str(point),
            'profile': profile.value,
            'time_limit': time_limit,
            'buckets': 3
        })

            # 生成语音文本

                text = "已到达目的地，导航结束"
            elif i == 0:
                street = inst.get('street_name', '')
                text = f"出发，{action_text}{'进入' + street if street else ''}"
            else:
                dist_text = self._format_distance(inst['distance'])
                street = inst.get('street_name', '')
                text = f"前方{dist_text}，{action_text}{'进入' + street if street else ''}"
            
            instructions.append(NavigationInstruction(
                index=i,
                text=text,
                distance=inst['distance'],
                distance_text=self._format_distance(inst['distance']),
                time=inst['time'],
                street_name=inst.get('street_name', ''),

            inst = self.current_route['instructions'][self.current_instruction]

            # 触觉反馈

            'right': [200, 100, 200],
            'straight': [100],
            'arrive': [100, 100, 100, 100, 100]
        }
        pattern = patterns.get(action, [50])
```

```javascript
const fetch = require('node-fetch');

class GraphHopperAPI {
    constructor(apiKey) {
        this.apiKey = apiKey;
        this.baseUrl = 'https://graphhopper.com/api/1';
    }
    
    async request(endpoint, params, method = 'GET') {
        const url = new URL(`${this.baseUrl}/${endpoint}`);
        url.searchParams.append('key', this.apiKey);
        
        if (method === 'GET') {
            Object.entries(params).forEach(([key, value]) => {
                if (Array.isArray(value)) {
                    value.forEach(v => url.searchParams.append(key, v));
                } else {
                    url.searchParams.append(key, value);
                }
            });
        }
        
        const options = {
            method,
            headers: method === 'POST' ? { 'Content-Type': 'application/json' } : {}
        };
        
        if (method === 'POST') {
            options.body = JSON.stringify(params);
        }
        
        const response = await fetch(url.toString(), options);
        
        if (!response.ok) {
            if (response.status === 401) throw new Error('API Key 无效');
            if (response.status === 429) throw new Error('API 额度已用完');
            throw new Error(`HTTP ${response.status}: ${response.statusText}`);
        }
        
        return response.json();
    }
    
    async geocode(query, locale = 'zh_CN') {
        const result = await this.request('geocode', { q: query, locale, limit: 5 });
        return result.hits.map(hit => ({
            name: hit.name,
            lat: hit.point.lat,
            lon: hit.point.lng,
            address: `${hit.street || ''}, ${hit.city || ''}, ${hit.country || ''}`
        }));
    }
    
    async route(fromPoint, toPoint, profile = 'foot', locale = 'zh_CN') {
        const result = await this.request('route', {
            point: [`${fromPoint.lat},${fromPoint.lon}`, `${toPoint.lat},${toPoint.lon}`],
            profile,
            locale,
            instructions: 'true',
            calc_points: 'true',
            points_encoded: 'false',
            elevation: 'true',
            details: ['road_class', 'surface']
        });
        
        if (!result.paths || result.paths.length === 0) {
            throw new Error('未找到路线');
        }
        
        return result.paths[0];
    }
}

class VisualNavigator {
    constructor(apiKey) {
        this.api = new GraphHopperAPI(apiKey);
        this.currentRoute = null;
        this.currentInstruction = 0;
        
        this.signMap = {
            0: ['继续直行', 'straight'],
            [-2]: ['左转', 'left'],
            2: ['右转', 'right'],
            [-3]: ['向左急转', 'sharp_left'],
            3: ['向右急转', 'sharp_right'],
            [-1]: ['稍向左转', 'slight_left'],
            1: ['稍向右转', 'slight_right'],
            5: ['到达目的地', 'arrive'],
            4: ['到达途经点', 'via']
        };
    }
    
    async searchDestination(query) {
        console.log(`[搜索] 正在搜索: ${query}`);
        const results = await this.api.geocode(query);
        
        results.forEach((r, i) => {
            console.log(`  ${i + 1}. ${r.name} - ${r.address}`);
        });
        
        return results;
    }
    
    async planRoute(fromLocation, toLocation, profile = 'foot') {
        console.log(`[规划] 正在规划路线: ${fromLocation} -> ${toLocation}`);
        
        let fromPoint;
        if (fromLocation === '当前位置') {
            fromPoint = { lat: 39.9042, lon: 116.4074 };
        } else {
            const fromResults = await this.api.geocode(fromLocation);
            fromPoint = { lat: fromResults[0].lat, lon: fromResults[0].lon };
        }
        
        const toResults = await this.api.geocode(toLocation);
        const toPoint = { lat: toResults[0].lat, lon: toResults[0].lon };
        
        const path = await this.api.route(fromPoint, toPoint, profile);
        
        const instructions = this.parseInstructions(path.instructions || []);
        
        this.currentRoute = {
            from: fromPoint,
            to: toPoint,
            distance: path.distance,
            distanceText: this.formatDistance(path.distance),
            time: path.time,
            timeText: this.formatTime(path.time),
            points: path.points,
            instructions
        };
        
        this.currentInstruction = 0;
        
        this.speak(`路线已规划完成。总距离${this.currentRoute.distanceText}，` +
                   `预计步行时间${this.currentRoute.timeText}。`);
        
        return this.currentRoute;
    }
    
    parseInstructions(rawInstructions) {
        return rawInstructions.map((inst, i) => {
            const sign = inst.sign || 0;
            const [actionText, actionCode] = this.signMap[sign] || ['直行', 'straight'];
            
            let text;
            if (sign === 5) {
                text = '已到达目的地，导航结束';
            } else if (i === 0) {
                const street = inst.street_name || '';
                text = `出发，${actionText}${street ? '进入' + street : ''}`;
            } else {
                const distText = this.formatDistance(inst.distance);
                const street = inst.street_name || '';
                text = `前方${distText}，${actionText}${street ? '进入' + street : ''}`;
            }
            
            return {
                index: i,
                text,
                distance: inst.distance,
                distanceText: this.formatDistance(inst.distance),
                time: inst.time,
                streetName: inst.street_name || '',
                action: actionCode
            };
        });
    }
    
    startNavigation() {
        if (!this.currentRoute) {
            throw new Error('请先规划路线');
        }
        
        this.speak('开始导航。请按照语音指引行走。');
        
        if (this.currentRoute.instructions.length > 0) {
            this.speak(this.currentRoute.instructions[0].text);
        }
    }
    
    updateLocation(lat, lon) {
        if (!this.currentRoute) return;
        
        if (this.currentInstruction < this.currentRoute.instructions.length - 1) {
            this.currentInstruction++;
            const inst = this.currentRoute.instructions[this.currentInstruction];
            this.speak(inst.text);
            this.hapticFeedback(inst.action);
        }
    }
    
    speak(text) {
        console.log(`[语音] ${text}`);
    }
    
    hapticFeedback(action) {
        const patterns = {
            left: [100, 200, 100],
            right: [200, 100, 200],
            straight: [100],
            arrive: [100, 100, 100, 100, 100]
        };
        const pattern = patterns[action] || [50];
        console.log(`[震动] ${JSON.stringify(pattern)}`);
    }
    
    formatDistance(meters) {
        return meters < 1000 ? `${Math.round(meters)}米` : `${(meters / 1000).toFixed(1)}公里`;
    }
    
    formatTime(ms) {
        const minutes = Math.floor(ms / 60000);
        const hours = Math.floor(minutes / 60);
        return hours > 0 ? `${hours}小时${minutes % 60}分钟` : `${minutes}分钟`;
    }
}

// ==================== 主程序 ====================

async function main() {
    const apiKey = process.env.GRAPHHOPPER_API_KEY;
    if (!apiKey) {
        console.log('请设置 GRAPHHOPPER_API_KEY 环境变量');
        return;
    }
    
    const navigator = new VisualNavigator(apiKey);
    
    console.log('='.repeat(50));
    console.log('视障导航应用 - 演示');
    console.log('='.repeat(50));
    
    // 1. 搜索目的地
    console.log('\n[步骤 1] 搜索目的地');
    const results = await navigator.searchDestination('北京王府井');
    
    if (results.length === 0) {
        console.log('未找到结果');
        return;
    }
    
    // 2. 规划路线
    console.log('\n[步骤 2] 规划路线');
    try {
        const route = await navigator.planRoute('当前位置', '北京王府井', 'foot');
        
        console.log('\n路线概览:');
        console.log(`  距离: ${route.distanceText}`);
        console.log(`  时间: ${route.timeText}`);
        console.log(`  指令数: ${route.instructions.length}`);
    } catch (e) {
        console.log(`路线规划失败: ${e.message}`);
        return;
    }
    
    // 3. 开始导航
    console.log('\n[步骤 3] 开始导航');
    navigator.startNavigation();
    
    // 4. 模拟位置更新
    console.log('\n[步骤 4] 模拟行走');
    for (let i = 0; i < 3; i++) {
        await new Promise(r => setTimeout(r, 1000));
        navigator.updateLocation(39.9042 + i * 0.001, 116.4074 + i * 0.001);
    }
    
    console.log('\n' + '='.repeat(50));
    console.log('导航演示结束');
    console.log('='.repeat(50));
}

main().catch(console.error);
```
