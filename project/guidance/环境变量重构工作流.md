## **🚫 绝对红线规则 (Strict Guardrails)**

如果你的修改违反了以下任何一条规则，本次重构将被视为彻底失败：

1. **绝对纯后端修改**：这是一次 100% 的后端优化。**严禁**读取、修改或触碰 frontend/ 目录下的任何文件。  
2. **零 API 契约变更**：**严禁**修改任何对外暴露的路由路径（Routes）、请求体结构（Request Payload）或响应体结构（Response Payload）。前端与后端的通信接口必须保持 100% 不变。  
3. **严格的优先级逻辑**：环境变量的加载必须严格遵循以下优先级（高 \-\> 低）：  
   System Environment Variables (系统级环境变量) \> .env 文件 \> 代码级默认值  
   *注：必须确保 dotenv 的初始化机制不会意外覆盖操作系统中已存在的同名环境变量。*
